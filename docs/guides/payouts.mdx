# Retraits et payouts

<Warning>
  **Les payouts automatiques (`POST /v1/payouts`) ne sont pas disponibles.** Orange Money ne permet pas
  d'envoi d'argent automatique depuis SahelPay : une création de payout est refusée (`403` avec une clé de
  test, `400` « Les transferts automatiques Orange Money ne sont pas disponibles » avec une clé live).
  Les envois vers des fournisseurs, salariés ou partenaires ne sont donc pas proposés.
</Warning>

Pour récupérer votre argent, créez une **demande de retrait** de votre solde disponible vers Orange Money. Chaque demande est **vérifiée puis exécutée manuellement** par l'équipe SahelPay.

## Cycle de vie d'un retrait

| Statut | Description |
|--------|-------------|
| `PENDING` | Demande enregistrée, fonds réservés sur votre solde |
| `PROCESSING` | Prise en charge par SahelPay |
| `COMPLETED` | Transfert Orange Money effectué (référence de transfert enregistrée) |
| `REJECTED` | Demande refusée, fonds restitués |
| `CANCELLED` | Annulée par vous tant qu'elle était `PENDING` |

## Règles

| Règle | Valeur |
|-------|--------|
| Montant minimum | 50 000 FCFA |
| Montant maximum | 5 000 000 FCFA |
| Frais | 1 % du montant, minimum 100 FCFA, **déduits du montant** |
| Opérateur | `ORANGE_MONEY` uniquement |
| Prérequis | Compte actif et KYC approuvé |
| Idempotence | Header `X-Idempotency-Key` obligatoire |

Exemple : un retrait de 100 000 FCFA débite 100 000 FCFA de votre solde et vous recevez 99 000 FCFA.

<Note>
  Les membres du [Programme Partenaires SPAY](/guides/partners) n'ont pas de solde à retirer : SAHEL PAY TECHNOLOGIES leur verse leur redevance chaque mois (`403 PARTNER_WITHDRAWAL_CLOSED`).
</Note>

## Vérifier votre solde et le devis

```bash
curl https://api.sahelpay.ml/v1/withdrawals/balance \
  -H "Authorization: Bearer sk_live_xxx"

curl "https://api.sahelpay.ml/v1/withdrawals/quote?amount=100000" \
  -H "Authorization: Bearer sk_live_xxx"
```

Le devis renvoie `amount`, `fee`, `amount_debited`, `recipient_amount`, `currency` et `provider`. Passez `quoted_fee` à la création : si les frais ont changé entre-temps, la demande est refusée (`409`) au lieu d'être exécutée à un autre prix.

## Créer une demande de retrait

```bash
curl -X POST https://api.sahelpay.ml/v1/withdrawals \
  -H "Authorization: Bearer sk_live_xxx" \
  -H "Content-Type: application/json" \
  -H "X-Idempotency-Key: withdrawal-2026-10-03" \
  -d '{
    "amount": 100000,
    "quoted_fee": 1000,
    "provider": "ORANGE_MONEY",
    "phone_number": "+22370123456",
    "notes": "Retrait hebdomadaire"
  }'
```

Rejouer la même clé avec la même demande renvoie la demande existante ; la même clé avec un autre montant ou un autre numéro est refusée (`409`).

<Warning>
  Les helpers `withdrawals.create()` des SDK JavaScript et Python n'envoient pas encore les champs attendus
  (`provider`, `phone_number`) ni le header `X-Idempotency-Key` : utilisez l'appel HTTP ci-dessus ou le dashboard.
  `withdrawals.balance()`, `withdrawals.list()`, `withdrawals.stats()` et `withdrawals.cancel()` fonctionnent.
</Warning>

## Suivre et annuler

```javascript
const balance = await sahelpay.withdrawals.balance();
console.log(balance.available_balance);

const result = await sahelpay.withdrawals.list({ page: 1, limit: 20 });

// Annuler une demande encore PENDING
await sahelpay.withdrawals.cancel('withdrawal_id');
```

Voir la référence : [Créer un retrait](/api-reference/withdrawals/create) et [Lister, solde, annulation](/api-reference/withdrawals/list).
