# Tests

Utilisez l'environnement sandbox pour tester votre intégration avant de passer en production.

## Environnement Sandbox

| | Sandbox | Production |
|---|---------|------------|
| **URL** | `https://api.sahelpay.ml` | `https://api.sahelpay.ml` |
| **Clés** | `sk_test_xxx` | `sk_live_xxx` |
| **Transactions** | Test provider ou simulateur SahelPay | Réelles |

Le sandbox est un mode logique porté par la clé `sk_test_...`. N'utilisez pas de base URL différente pour les SDK.

## Numéros de test

Utilisez ces numéros pour simuler différents scénarios :

| Numéro | Résultat |
|--------|----------|
| `+22370000001` | ✅ Paiement réussi |
| `+22370000002` | ❌ Paiement échoué |
| `+22370000003` | ⏳ Paiement en attente (timeout) |
| `+22370000004` | 🚫 Solde insuffisant |

## Montants de test

Avec le simulateur SahelPay (`metadata.sandbox: true` ou option SDK `sandbox: true`) :

| Montant | Comportement |
|---------|--------------|
| `4000` | Paiement réussi |
| `4001` | Paiement échoué |
| `4002` | Paiement en attente |
| `4003` | Paiement échoué |
| Autre montant valide | Paiement réussi |

```bash
curl -X POST https://api.sahelpay.ml/v1/payments \
  -H "Authorization: Bearer sk_test_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 4000,
    "currency": "XOF",
    "payment_method": "ORANGE_MONEY",
    "customer_phone": "+22370123456",
    "return_url": "https://votre-site.com/checkout/return",
    "metadata": { "sandbox": true, "order_id": "order_test_1" }
  }'
```

## Tester les webhooks

### Avec ngrok (local)

```bash
# Exposer votre serveur local
ngrok http 3000

# Configurer l'URL dans le dashboard
# https://xxxx.ngrok.io/api/webhooks/sahelpay
```

### Déclencher un webhook manuellement

```bash
curl -X POST https://api.sahelpay.ml/v1/webhooks/test \
  -H "Authorization: Bearer sk_test_xxx" \
  -H "Content-Type: application/json" \
  -d '{}'
```

Cet endpoint envoie un événement `webhook.test` vers l'URL webhook configurée dans le dashboard. Pour tester un vrai webhook métier `payment.success` ou `payment.failed`, créez un paiement avec `metadata.sandbox: true`, puis appelez `GET /v1/payments/{id}/status`.
