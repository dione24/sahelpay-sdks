# Méthode de paiement

<Warning>
  **Orange Money (Mali) est le seul moyen de paiement.** Wave, Moov, les cartes
  bancaires (Visa, Mastercard, GIM-UEMOA) et les autres fournisseurs ont été
  retirés : toute autre valeur de `provider` ou de `payment_method` est rejetée
  avec une erreur `400`, jamais routée ailleurs en silence.
</Warning>

## Valeurs acceptées

| Champ | Valeurs acceptées |
|-------|-------------------|
| `payment_method` | `MOBILE_MONEY`, ou les alias `ORANGE_MONEY` / `ORANGE` |
| `provider` (ancien champ) | `ORANGE_MONEY`, `ORANGE`, `MOBILE_MONEY` |
| `country` | `ML` (défaut) |
| `currency` | `XOF` (défaut) |

## Vérifier la disponibilité

Orange Money peut être mis en maintenance ou désactivé côté SahelPay. Dans ce cas, la création de paiement échoue avec un `400` explicite. Pour l'afficher à vos clients avant le paiement, interrogez l'endpoint public :

```bash
curl https://api.sahelpay.ml/v1/providers/enabled
```

```json
{
  "success": true,
  "data": [
    {
      "provider": "ORANGE_MONEY",
      "display_name": "Orange Money",
      "category": "MOBILE_MONEY",
      "logo_url": null,
      "min_amount": null,
      "max_amount": null
    }
  ]
}
```

Une liste vide signifie qu'Orange Money est momentanément indisponible. Paramètre optionnel : `country` (`ML` par défaut).

## Endpoints historiques

`GET /v1/payments/providers` et `GET /v1/payments/recommend?phone=...` existent toujours mais ne renvoient plus qu'Orange Money Mali (`ORANGE_MONEY_ML`). `recommend` indique seulement, via `confidence`, si le numéro ressemble à un numéro Orange Mali.
