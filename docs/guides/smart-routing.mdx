# Méthode de paiement

<Warning>
  **Le mobile money au Mali (`ORANGE_MONEY`) est le seul moyen de paiement.**
  Toute autre valeur de `provider` ou de `payment_method` est rejetée
  avec une erreur `400`, jamais routée ailleurs en silence.
</Warning>

## Valeurs acceptées

| Champ | Valeurs acceptées |
|-------|-------------------|
| `payment_method` | `MOBILE_MONEY`, ou l’alias `ORANGE_MONEY` |
| `provider` (ancien champ) | `ORANGE_MONEY`, `MOBILE_MONEY` |
| `country` | `ML` (défaut) |
| `currency` | `XOF` (défaut) |

## Vérifier la disponibilité

Le moyen de paiement peut être mis en maintenance ou désactivé côté SahelPay. Dans ce cas, la création de paiement échoue avec un `400` explicite. Pour l'afficher à vos clients avant le paiement, interrogez l'endpoint public :

```bash
curl https://api.sahelpay.ml/v1/providers/enabled
```

```json
{
  "success": true,
  "data": [
    {
      "provider": "ORANGE_MONEY",
      "display_name": "Orange Money",
      "category": "MOBILE_MONEY",
      "logo_url": null,
      "min_amount": null,
      "max_amount": null
    }
  ]
}
```

Une liste vide signifie que le moyen de paiement est momentanément indisponible. Paramètre optionnel : `country` (`ML` par défaut).

## Endpoints historiques

`GET /v1/payments/providers` et `GET /v1/payments/recommend?phone=...` existent toujours mais ne renvoient plus que le moyen de paiement disponible (`ORANGE_MONEY_ML`). `recommend` indique seulement, via `confidence`, si le numéro ressemble à un numéro Orange Mali.
