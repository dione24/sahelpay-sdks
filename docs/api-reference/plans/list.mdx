# Lister les plans

## Endpoint

```
GET /v1/billing/plans
```

## Exemple

```bash
curl https://api.sahelpay.ml/v1/billing/plans \
  -H "Authorization: Bearer sk_test_xxx"
```

## Réponse

```json
{
  "success": true,
  "data": [
    {
      "id": "...",
      "name": "Premium Mensuel",
      "description": null,
      "amount": 10000,
      "currency": "XOF",
      "interval": "MONTHLY",
      "is_active": true,
      "subscriber_count": 12,
      "created_at": "2026-10-03T10:00:00.000Z"
    }
  ]
}
```

## Plans publics

`GET /v1/public/plans?merchant_id=...` (sans clé) renvoie vos plans actifs pour une page de pricing ; `GET /v1/public/plans/{id}` renvoie un plan. Côté SDK JS : `SahelPay.getPublicPlans(merchantId)` et `SahelPay.getPublicPlan(planId)`.

## Pagination

`take` de 1 à 200 (défaut 50), `cursor` opaque. La réponse conserve `data[]` et
ajoute `pagination: {total, take, next_cursor, has_more}` à la racine. JavaScript :
`plans.listPage({take, cursor})`, Python : `plans.list_page(take=..., cursor=...)`.
Les méthodes `list()` existantes conservent leur tableau/liste.
