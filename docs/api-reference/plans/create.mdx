# Créer un plan

## Endpoint

```
POST /v1/billing/plans
```

<Warning>
  Les helpers `plans.create()` des SDKs appellent encore `POST /v1/plans`, qui n'existe pas. Utilisez l'appel HTTP.
</Warning>

## Body

| Paramètre | Type | Requis | Description |
|-----------|------|--------|-------------|
| `name` | string | ✅ | Nom du plan |
| `amount` | integer | ✅ | Montant par période (FCFA) |
| `interval` | string | ✅ | `WEEKLY` ou `MONTHLY` |
| `description` | string | | Description |

## Exemple

```bash
curl -X POST https://api.sahelpay.ml/v1/billing/plans \
  -H "Authorization: Bearer sk_test_xxx" \
  -H "Content-Type: application/json" \
  -d '{ "name": "Premium Mensuel", "amount": 10000, "interval": "MONTHLY" }'
```

## Réponse

`201 Created`

```json
{
  "success": true,
  "data": {
    "id": "...",
    "name": "Premium Mensuel",
    "description": null,
    "amount": 10000,
    "currency": "XOF",
    "interval": "MONTHLY",
    "is_active": true,
    "created_at": "2026-10-03T10:00:00.000Z"
  }
}
```

## Modifier ou supprimer

- `PATCH /v1/billing/plans/{id}` : `name`, `description`, `amount`, `is_active`.
- `DELETE /v1/billing/plans/{id}` : supprime le plan, ou le désactive s'il a déjà des abonnements (`data.deleted: false`).
