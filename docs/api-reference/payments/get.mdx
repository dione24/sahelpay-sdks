# Statut d'un paiement

## Endpoint authentifié (recommandé)

```
GET /v1/payments/{id}/status
```

| Paramètre | Type | Description |
|-----------|------|-------------|
| `id` | string | ID du paiement renvoyé à la création (UUID) |

```bash
curl https://api.sahelpay.ml/v1/payments/8d6f1c2e-.../status \
  -H "Authorization: Bearer sk_test_xxx"
```

Pour un paiement simulé (`sahelpay_mock`), cet appel applique le statut simulé et déclenche le webhook correspondant.

SDKs : `sahelpay.payments.retrieve(id)` / `checkStatus(id)` (JS), `client.payments.retrieve(id)` / `check_status(id)` (Python), `$sahelpay->payments->verify($id)` (PHP).

<Note>
  Si le paiement est introuvable, la réponse est `200` avec `{ "success": false, "message": "PaymentIntent not found" }`.
</Note>

## Endpoint public

```
GET /v1/payments/{id}
```

Sans clé API (20 requêtes par minute) : utilisé par les pages de paiement SahelPay. Il renvoie `id`, `status`, les montants, `currency`, `reference` (votre `client_reference` ou un code court), `return_url`, `created_at` et `updated_at`. Si un paiement est `PENDING` depuis plus de quelques secondes, l'appel déclenche une revérification auprès d'Orange Money.

## Statuts

| Statut | Description |
|--------|-------------|
| `INITIATED` | Créé, pas encore initié auprès d'Orange |
| `PENDING` | En attente de validation du client |
| `SUCCESS` | Paiement confirmé |
| `FAILED` | Paiement échoué |
| `EXPIRED` | Expiré (délai écoulé ou `POST /v1/payments/{id}/expire`) |
