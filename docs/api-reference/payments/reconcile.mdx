# Réconcilier un paiement

Si un paiement reste `PENDING` (par exemple après un webhook manqué), cet endpoint demande à SahelPay de revérifier son statut auprès de l'opérateur et de le mettre à jour. Un changement de statut déclenche le webhook correspondant.

Limite : 10 appels par minute.

## Path Parameters

| Paramètre | Type | Requis | Description |
|-----------|------|--------|-------------|
| `id` | string | ✅ | ID du paiement (UUID) |

## Exemple

```bash
curl -X POST https://api.sahelpay.ml/v1/payments/8d6f1c2e-.../reconcile \
  -H "Authorization: Bearer sk_live_xxx"
```

SDKs : `payments.reconcile(id)` (JS, Python), `$sahelpay->payments->reconcile($id)` (PHP).

## Réponse

```json
{
  "success": true,
  "data": {
    "id": "8d6f1c2e-...",
    "updated": true,
    "new_status": "SUCCESS",
    "message": "PaymentIntent status updated to SUCCESS"
  }
}
```

Si rien n'a changé : `updated: false` et `"message": "PaymentIntent still PENDING or already finalized"`. Si la vérification est impossible pour le moment : `200` avec `success: false` et un message invitant à réessayer.

<Info>
  SahelPay réconcilie aussi automatiquement les paiements `PENDING` en arrière-plan.
</Info>
