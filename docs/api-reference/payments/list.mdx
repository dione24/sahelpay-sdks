# Historique des transactions

## Endpoint

```
GET /v1/payments/history
```

<Warning>
  Cet endpoint lit l'historique des **transactions de l'ancien flux** de paiement. Les paiements créés via
  `POST /v1/payments` n'y figurent pas : pour eux, utilisez les webhooks, `GET /v1/payments/search`
  (par `client_reference`) ou `GET /v1/payments/{id}/details`, ou les exports du dashboard.
</Warning>

## Query parameters

| Paramètre | Type | Description |
|-----------|------|-------------|
| `limit` | integer | Résultats (défaut 20, max 100) |
| `offset` | integer | Décalage (défaut 0) |
| `status` | string | Filtrer par statut |
| `start_date` | string | `created_at >=` (ISO ou `YYYY-MM-DD`) |
| `end_date` | string | `created_at <=` (ISO ou `YYYY-MM-DD`) |

## Exemple

```bash
curl "https://api.sahelpay.ml/v1/payments/history?limit=20&offset=0&status=SUCCESS" \
  -H "Authorization: Bearer sk_test_xxx"
```
