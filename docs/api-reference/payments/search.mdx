# Rechercher un paiement

Retrouve un paiement à partir de votre propre référence (`client_reference`). Utile pour la page de retour et la réconciliation.

## Query Parameters

| Paramètre | Type | Requis | Description |
|-----------|------|--------|-------------|
| `client_reference` | string | ✅ | Votre référence interne (ex : ID de commande) |

## Exemple

<CodeGroup>

```bash cURL
curl "https://api.sahelpay.ml/v1/payments/search?client_reference=order-123" \
  -H "Authorization: Bearer sk_live_xxx"
```

```javascript Node.js
const payment = await sahelpay.payments.search('order-123'); // null si introuvable
```

```python Python
payment = client.payments.search('order-123')
```

```php PHP
$payment = $sahelpay->payments->search('order-123');
```

</CodeGroup>

## Réponse

Retourne le paiement le plus récent portant cette référence.

```json
{
  "success": true,
  "data": {
    "id": "8d6f1c2e-...",
    "status": "SUCCESS",
    "amount": 5000,
    "amount_charged": 5000,
    "amount_merchant_net": 4950,
    "fee_total": 50,
    "currency": "XOF",
    "client_reference": "order-123",
    "provider_ref": "MP261003.1000.A12345",
    "metadata": {
      "customer": { "phone": "+22370123456" },
      "description": "Commande #123"
    },
    "ledger_entries": [],
    "created_at": "2026-10-03T10:00:00.000Z",
    "updated_at": "2026-10-03T10:05:00.000Z",
    "expires_at": "2026-10-03T10:30:00.000Z"
  }
}
```

## Cas sans résultat

L'API répond `200` avec `success: false` :

```json
{ "success": false, "message": "PaymentIntent not found" }
```

(ou `"client_reference is required"` si le paramètre manque).
