# Détails du paiement

Récupère les informations complètes d'un paiement : montants, client, URLs et métadonnées. Utile pour la réconciliation et l'audit.

## Path Parameters

| Paramètre | Type | Requis | Description |
|-----------|------|--------|-------------|
| `id` | string | ✅ | ID du paiement (UUID) |

## Exemple

<CodeGroup>

```bash cURL
curl https://api.sahelpay.ml/v1/payments/8d6f1c2e-.../details \
  -H "Authorization: Bearer sk_live_xxx"
```

```javascript Node.js
const payment = await sahelpay.payments.details('8d6f1c2e-...');
```

```python Python
payment = client.payments.details('8d6f1c2e-...')
```

```php PHP
$payment = $sahelpay->payments->details('8d6f1c2e-...');
```

</CodeGroup>
