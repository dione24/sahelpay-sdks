# Remboursements : indisponibles

<Warning>
  **Les remboursements en ligne sont désactivés en production pour l'instant.** `POST /v1/refunds`
  répond toujours HTTP `503` (refus `REFUNDS_UNAVAILABLE` côté serveur), sans réserver de fonds.

  Pour rembourser un client, contactez le support : [support@sahelpay.africa](mailto:support@sahelpay.africa),
  en indiquant l'ID du paiement et le montant.
</Warning>

## Réponse actuelle

Comme toute erreur `5xx`, la réponse publique est normalisée : testez le statut HTTP `503` plutôt que le code.

```json
{
  "success": false,
  "error": {
    "code": "SERVICE_UNAVAILABLE",
    "message": "Le service est momentanément indisponible. Réessayez ou contactez le support.",
    "http_status": 503
  }
}
```

<Note>
  Les helpers `refunds.create()` des SDKs reçoivent cette même erreur. `refunds.list()` (JS, Python, PHP)
  appelle `GET /v1/refunds`, qui n'existe pas.
</Note>

## Paiement sécurisé à la livraison

Les remboursements liés au [paiement sécurisé à la livraison](/guides/secure-orders) ne sont pas concernés :
annuler une commande payée (`POST /v1/secure-orders/{id}/cancel`) rembourse l'acheteur, et un délai de
livraison dépassé déclenche un remboursement automatique.
