# Annuler un abonnement

## Endpoint

```
DELETE /v1/billing/subscriptions/{id}
```

<Warning>
  Les helpers `subscriptions.cancel()` des SDKs appellent encore `DELETE /v1/subscriptions/{id}`, qui n'existe pas.
</Warning>

## Exemple

```bash
curl -X DELETE https://api.sahelpay.ml/v1/billing/subscriptions/SUBSCRIPTION_ID \
  -H "Authorization: Bearer sk_test_xxx"
```

## Réponse

```json
{ "success": true }
```

L'abonnement passe immédiatement à `CANCELLED` ; aucune nouvelle échéance n'est générée. Abonnement inconnu : `400` « Subscription not found ».
