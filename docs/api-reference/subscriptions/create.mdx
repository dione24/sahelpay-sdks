# Créer un abonnement

<Warning>
  Les helpers `subscriptions.create()` / `createWithPayment()` des SDKs appellent encore `/v1/subscriptions`,
  qui n'existe pas. Utilisez les appels HTTP ci-dessous.
</Warning>

## Avec premier lien de paiement (recommandé)

```
POST /v1/billing/subscriptions/with-payment
```

| Paramètre | Type | Requis | Description |
|-----------|------|--------|-------------|
| `plan_id` | string | ✅ | Plan actif |
| `customer_phone` | string | ✅ | Téléphone du client |
| `redirect_url` | string | | Retour après paiement |
| `metadata` | object | | Données libres, copiées sur la facture |

L'abonnement est créé `INCOMPLETE` et devient `ACTIVE` après le premier paiement.

```bash
curl -X POST https://api.sahelpay.ml/v1/billing/subscriptions/with-payment \
  -H "Authorization: Bearer sk_test_xxx" \
  -H "Content-Type: application/json" \
  -d '{ "plan_id": "PLAN_ID", "customer_phone": "+22370123456" }'
```

```json
{
  "success": true,
  "data": {
    "subscription": {
      "id": "...",
      "plan_id": "PLAN_ID",
      "plan_name": "Premium Mensuel",
      "plan_amount": 10000,
      "customer_phone": "+22370123456",
      "status": "INCOMPLETE",
      "next_billing_date": "2026-10-03T10:00:00.000Z",
      "created_at": "2026-10-03T10:00:00.000Z"
    },
    "invoice": { "id": "...", "invoice_number": "...", "status": "OPEN", "total": 10000, "amount_due": 10000 },
    "payment_link": { "id": "...", "url": "https://pay.sahelpay.ml/<slug>", "amount": 10000 }
  }
}
```

## Sans paiement immédiat

```
POST /v1/billing/subscriptions
```

| Paramètre | Type | Requis | Description |
|-----------|------|--------|-------------|
| `plan_id` | string | ✅ | Plan actif |
| `customer_phone` | string | ✅ | Téléphone du client |
| `start_date` | string | | Date ISO de première échéance (défaut : maintenant) |

Crée directement un abonnement `ACTIVE`. Réponse : `id`, `plan_id`, `plan_name`, `customer_phone`, `status`, `next_billing_date`, `created_at`.

## Erreurs

`400` « Plan not found » ou « Plan inactive ».
