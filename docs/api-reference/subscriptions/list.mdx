# Lister les abonnements

## Endpoint

```
GET /v1/billing/subscriptions
```

| Paramètre | Type | Description |
|-----------|------|-------------|
| `status` | string | `INCOMPLETE`, `ACTIVE`, `PAST_DUE` ou `CANCELLED` |

<Warning>
  Les helpers `subscriptions.list()` des SDKs appellent encore `GET /v1/subscriptions`, qui n'existe pas.
</Warning>

## Exemple

```bash
curl "https://api.sahelpay.ml/v1/billing/subscriptions?status=ACTIVE" \
  -H "Authorization: Bearer sk_test_xxx"
```
