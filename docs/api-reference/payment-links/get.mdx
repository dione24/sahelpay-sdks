# Lister et récupérer des liens de paiement

## Endpoints

| Endpoint | Méthode | Auth | Description |
|----------|---------|------|-------------|
| `/v1/payment-links` | `GET` | Clé secrète | Lister vos liens |
| `/v1/payment-links/{slug}` | `GET` | Public | Lien par slug (vue publique utilisée par le checkout) |
| `/v1/payment-links/{id}/activate` | `PATCH` | Clé secrète | Activer |
| `/v1/payment-links/{id}/deactivate` | `PATCH` | Clé secrète | Désactiver |
| `/v1/payment-links/{id}` | `DELETE` | Clé secrète | Supprimer |
| `/v1/payment-links/{slug}/qr` | `GET` | Public | QR code (`data.qr_code`) |

## Exemple

```bash
curl https://api.sahelpay.ml/v1/payment-links \
  -H "Authorization: Bearer sk_test_xxx"

curl https://api.sahelpay.ml/v1/payment-links/3f9a1c0b8e7d4a2f9c1b0e6d5a4f3c2b
```

La vue publique par slug renvoie les informations affichables du lien et un `checkout_session` (jeton de session de paiement à durée limitée). Un slug inconnu ou mal formé renvoie `404 PAYMENT_LINK_NOT_FOUND`.

SDKs : `paymentLinks.list()` / `retrieve(slug)` / `activate(id)` / `deactivate(id)` / `qrCode(slug)` (JS), `payment_links.*` (Python, sans QR), `$sahelpay->paymentLinks->all()` / `get($slug)` / `qrCode($slug)` (PHP).
