# Événements webhook

## Événements émis

| Événement | Description |
|-----------|-------------|
| `payment.success` | Paiement confirmé |
| `payment.failed` | Paiement échoué |
| `payment.pending` | Paiement en attente de confirmation opérateur |
| `payment.expired` | Paiement expiré (délai écoulé, `POST /v1/payments/{id}/expire` ou réconciliation) |
| `payment.updated` | Autre changement de statut |
| `invoice.created` | Facture d'échéance d'abonnement créée (avec `payment_url`) |
| `subscription.payment_due` | Échéance d'abonnement (compatibilité, avec `payment_url`) |
| `invoice.paid` | Facture réglée |
| `subscription.renewed` | Abonnement prolongé après paiement |
| `webhook.test` | Test de connectivité |

<Note>
  `payment.cancelled` n'est pas émis : une expiration produit toujours `payment.expired`.
</Note>

## Enveloppe

```json
{
  "id": "evt_1759480000000_9f2c4e1a7b3d5c60",
  "event": "payment.success",
  "version": "v1",
  "timestamp": "2026-10-03T10:05:00.000Z",
  "data": { }
}
```

Le contenu de `data` pour les paiements est détaillé dans le [guide webhooks](/guides/webhooks#format-du-payload-paiement).

## Headers

| Header | Description |
|--------|-------------|
| `X-SahelPay-Signature` | `t=<timestamp>,v1=<signature>` |
| `X-SahelPay-Timestamp` | Timestamp UNIX (secondes) |
| `X-SahelPay-Event-ID` | ID unique de l'événement |
| `X-SahelPay-Signature-Algorithm` | `HMAC-SHA256` |
| `X-Request-ID` | Identifiant de corrélation |
| `Content-Type` | `application/json` |
