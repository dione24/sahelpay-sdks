# Lister et consulter les paiements sécurisés

## Endpoints

| Endpoint | Méthode | Description |
|----------|---------|-------------|
| `/v1/secure-orders` | `GET` | Liste paginée |
| `/v1/secure-orders/{id}` | `GET` | Détail (`id` = UUID) |

## Liste : paramètres

| Paramètre | Type | Description |
|-----------|------|-------------|
| `status` | string | `CREATED`, `PAID_HELD`, `RELEASED`, `REFUNDED`, `DISPUTED`, `CANCELLED` |
| `search` | string | Recherche texte (100 caractères max) |
| `page` | integer | Page (≥ 1) |
| `limit` | integer | Taille de page (1 à 100) |

La liste renvoie `data.orders` (tableau d'objets ci-dessous) avec ses informations de pagination.

## Exemple

```bash
curl https://api.sahelpay.ml/v1/secure-orders/5f0c2c55-... \
  -H "Authorization: Bearer sk_test_xxx"
```

## Objet paiement sécurisé

| Champ | Description |
|-------|-------------|
| `id`, `reference` | Identifiants SahelPay |
| `status` | Statut de la commande |
| `is_test` | `true` pour une commande sandbox |
| `amount`, `currency` | Montant de la commande (XOF) |
| `amount_charged`, `fee_total`, `amount_merchant_net` | Montant payé, frais, net marchand |
| `description`, `customer_phone`, `customer_name`, `client_reference` | Données de la commande |
| `payment_intent_id`, `payment_status` | Paiement Orange Money associé |
| `buyer_url`, `delivery_url` | Liens acheteur et livreur |
| `delivery_window_hours`, `pay_before`, `delivery_deadline`, `delivery_expired` | Délais |
| `code_attempts`, `code_attempts_remaining`, `code_locked` | Suivi du code de livraison |
| `dispute_reason`, `resolution`, `cancel_reason`, `refund_reason`, `release_source`, `refund_id` | Issue de la commande |
| `created_at`, `paid_at`, `released_at`, `refunded_at`, `disputed_at`, `resolved_at`, `cancelled_at`, `updated_at` | Horodatages |
