# Comptes de test

Utilisez ces données pour tester votre intégration en sandbox (gratuite, sans abonnement).

## Déclencheurs du simulateur

Avec `metadata.sahelpay_mock: true` (option SDK `mock`), le statut final est piloté par le **montant** :

| Montant | Résultat |
|---------|----------|
| `4000` | ✅ Paiement réussi |
| `4001` | ❌ Échec — solde insuffisant |
| `4002` | ⏳ Paiement en attente |
| `4003` | ❌ Échec — erreur opérateur |
| Autre montant valide | ✅ Paiement réussi |

<Note>
  Il n'y a pas de numéros de téléphone de test : le simulateur ne regarde que le
  montant. Utilisez un numéro malien valide au format international `+223XXXXXXXX`.
  Créez le paiement avec `hosted_checkout: false`, puis lisez `GET /v1/payments/{id}/status`.
</Note>

## Clés de test

```
Public Key:     pk_test_xxxxxxxxxxxxxxxx
Secret Key:     sk_test_xxxxxxxxxxxxxxxx
Webhook Secret: whsec_xxxxxxxxxxxxxxxx
```

Vos vraies clés de test sont dans le dashboard (**Développeurs** → **Clés API**).

<Note>
  Les clés de test utilisent la base URL `https://api.sahelpay.ml`. Avec `metadata.sahelpay_mock: true`, le simulateur SahelPay répond sans appel opérateur ; avec `metadata.sandbox: true`, l'appel part vers l'environnement de test d'Orange. Ces deux métadonnées sont refusées en production.
</Note>
