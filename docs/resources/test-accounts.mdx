# Comptes de test

Utilisez ces données pour tester votre intégration en sandbox.

## Déclencheurs du simulateur

Avec `metadata.sahelpay_mock: true`, le statut final est piloté par le **montant** :

| Montant | Résultat |
|---------|----------|
| `4000` | ✅ Paiement réussi |
| `4001` | ❌ Échec — solde insuffisant |
| `4002` | ⏳ Paiement en attente |
| `4003` | ❌ Échec — erreur opérateur |
| Autre montant valide | ✅ Paiement réussi |

<Note>
  Il n'y a pas de numéros de téléphone de test : le simulateur ne regarde que le
  montant. Utilisez un numéro malien valide au format `+223XXXXXXXX`.
</Note>

## Clés API de test

```
Public Key: pk_test_xxxxxxxxxxxxxxxx
Secret Key: sk_test_xxxxxxxxxxxxxxxx
Webhook Secret: whsec_test_xxxxxxxx
```

<Note>
  Les clés de test utilisent la base URL `https://api.sahelpay.ml`. Pour le simulateur SahelPay sans appel opérateur, envoyez `metadata.sahelpay_mock: true`. Avec `metadata.sandbox: true`, l'appel part vers l'environnement de test de l'opérateur.
</Note>
