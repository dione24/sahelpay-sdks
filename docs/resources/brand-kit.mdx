## Règles d'usage

- **Zone de protection** : laissez autour du logo un vide égal à la moitié de la hauteur de l'icône. Pour un logo de 48 px de haut, au moins 24 px de chaque côté.
- **Taille minimale** : icône 16 px ; logo horizontal 96 px de large à l'écran, 25 mm à l'impression.
- **Clair ou sombre** : logo clair sur fond clair, logo sombre sur fond sombre. Les couleurs de l'icône sont fixes dans les deux modes : seul le mot-symbole change.
- **Sur une photo** : ne posez pas le logo clair sur une image chargée. Utilisez le logo sombre sur un aplat.
- **Le nom** s'écrit toujours **SahelPay**, en un mot, S et P majuscules.

<Warning>
  **À ne pas faire**

  - Changer les couleurs des flèches, les inverser ou les faire pivoter.
  - Étirer ou déformer le logo, ou modifier l'espacement entre l'icône et le texte.
  - Ajouter une ombre, un dégradé, un contour ou un effet 3D.
  - Remplacer l'icône par un autre pictogramme (portefeuille, bouclier, éclair) ou un emoji.
  - Écrire « Sahel Pay », « SAHELPAY » ou « Sahelpay ».
  - Redessiner le logo ou le recomposer avec une police : utilisez les fichiers fournis.
</Warning>

### React

Le composant réutilise la feuille CSS ci-dessus. Avec `href`, il rend un lien (lien de paiement). Sans `href`, il rend un `<button>` : votre `onClick` appelle votre backend, qui crée le paiement et renvoie le `redirect_url` du checkout hébergé.

<CodeGroup>

```tsx PayWithSahelPay.tsx
import type { MouseEventHandler } from "react";

type Props = {
  /** Lien de paiement (https://pay.sahelpay.africa/<slug>) ou redirect_url d'un paiement */
  href?: string;
  /** Sans href : appelez votre backend puis redirigez vers le redirect_url */
  onClick?: MouseEventHandler<HTMLButtonElement>;
  /** "clair" pour une page à fond clair, "sombre" pour une page à fond sombre */
  variant?: "clair" | "sombre";
  size?: "md" | "sm";
  loading?: boolean;
  disabled?: boolean;
};

export function PayWithSahelPay({ href, onClick, variant = "clair", size = "md", loading = false, disabled = false }: Props) {
  const className = ["sahelpay-btn", variant === "sombre" && "sahelpay-btn--sombre", size === "sm" && "sahelpay-btn--sm"]
    .filter(Boolean)
    .join(" ");

  const content = (
    <>
      <svg className="sahelpay-btn__icone" viewBox="0 0 64 64" aria-hidden="true" focusable="false">
        <rect width="64" height="64" rx="15" style={{ fill: "var(--sp-fond)" }} />
        <path d="M15 26H45L37 18" fill="none" strokeWidth={6} strokeLinecap="round" strokeLinejoin="round" style={{ stroke: "var(--sp-aller)" }} />
        <path d="M49 38H19L27 46" fill="none" strokeWidth={6} strokeLinecap="round" strokeLinejoin="round" style={{ stroke: "var(--sp-retour)" }} />
      </svg>
      <span>
        {loading ? "Redirection…" : <>Payer avec <span className="sahelpay-btn__sahel">Sahel</span><span className="sahelpay-btn__pay">Pay</span></>}
      </span>
    </>
  );

  if (href && !disabled) {
    return <a className={className} href={href} aria-label="Payer avec SahelPay">{content}</a>;
  }
  return (
    <button type="button" className={className} onClick={onClick} disabled={disabled || loading}
      aria-label="Payer avec SahelPay" aria-busy={loading}>
      {content}
    </button>
  );
}
```

```tsx Utilisation
// 1. Lien de paiement
<PayWithSahelPay href="https://pay.sahelpay.africa/VOTRE-SLUG" />

// 2. Checkout hébergé : le backend crée le paiement avec votre clé secrète
const [loading, setLoading] = useState(false);

<PayWithSahelPay
  loading={loading}
  onClick={async () => {
    setLoading(true);
    const res = await fetch("/api/payments/create", { method: "POST", body: JSON.stringify({ orderId }) });
    const { redirect_url } = await res.json();
    window.location.assign(redirect_url);
  }}
/>
```

</CodeGroup>

<Warning>
  Ne mettez jamais votre clé secrète (`sk_test_...`, `sk_live_...`) dans le navigateur ou une application mobile. La création du paiement se fait toujours sur votre serveur.
</Warning>

### Accessibilité

- Contrastes du texte : papier sur Vert Sahel 11,3:1, tilleul sur Vert Sahel 7,2:1, Vert Sahel sur papier 11,3:1, olive sur papier 4,7:1 (niveau AA ou mieux).
- Choisissez la version selon le fond de la page : le bouton Vert Sahel sur un fond Nuit ne se distingue presque plus (1,5:1).
- Le libellé accessible est « Payer avec SahelPay » (`aria-label`) ; l'icône est décorative (`aria-hidden`).
- Le focus clavier est visible (`:focus-visible`, contour de 3 px décalé du bouton).
- Gardez le libellé « Payer avec SahelPay » : il dit exactement ce qui se passe au clic.
