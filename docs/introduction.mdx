# Bienvenue sur SahelPay

SahelPay est une API technique de paiement au Mali : documentation, sandbox, webhooks signés et idempotence. **Orange Money (Mali) est le seul moyen de paiement disponible.** Wave, Moov et les cartes bancaires ne sont pas proposés : toute autre valeur de `provider` est rejetée avec une erreur `400`.

## Flow de paiement

```mermaid
sequenceDiagram
    participant Client
    participant Votre App
    participant SahelPay
    participant Orange as Orange Money

    Client->>Votre App: Clic "Payer"
    Votre App->>SahelPay: POST /v1/payments (X-Idempotency-Key)
    SahelPay-->>Votre App: redirect_url
    Votre App->>Client: Redirection
    Client->>SahelPay: Checkout
    SahelPay->>Orange: Initie le paiement
    Orange-->>Client: Validation Orange Money
    SahelPay->>Votre App: Webhook payment.success
    SahelPay-->>Client: Retour vers votre return_url (après confirmation)
```

## Méthode de paiement

| Méthode | Statut | Pays |
|---------|--------|------|
| `ORANGE_MONEY` | ✅ Disponible | Mali |

<Note>
  Utilisez toujours une clé `sk_test_...` pour vos tests. Pour simuler un paiement sans aucun appel opérateur, envoyez `metadata.sahelpay_mock: true` (option `mock` des SDKs).
</Note>

## Fonctionnalités principales

- **Paiements** : création et suivi de paiements Orange Money avec checkout hébergé
- **Liens de paiement** : liens réutilisables à montant fixe ou libre
- **Webhooks** : notifications signées pour chaque changement de statut
- **Idempotence** : création rejouable sans doublon
- **Programme Partenaires SPAY** : SahelPay vend en son nom les produits validés de votre catalogue
- **Abonnements clients** et **Customer Portal**

<Note>
  SAHEL PAY TECHNOLOGIES (SPAY) n'est pas une banque ni un établissement de paiement agréé par la BCEAO.
</Note>
