## Fonctionnalités par SDK

| Fonction | JS | PHP | Python | État côté API |
|----------|----|-----|--------|---------------|
| Créer un paiement | `payments.create()` | `payments->initiate()` | `payments.create()` | ✅ |
| Statut | `payments.retrieve()` / `checkStatus()` | `payments->verify()` | `payments.retrieve()` / `check_status()` | ✅ |
| Rechercher par référence | `payments.search()` | `payments->search()` | `payments.search()` | ✅ |
| Détails | `payments.details()` | `payments->details()` | `payments.details()` | ✅ |
| Réconcilier | `payments.reconcile()` | `payments->reconcile()` | `payments.reconcile()` | ✅ |
| Polling | `payments.poll()` | — | `payments.poll()` | ✅ |
| Historique | `payments.list()` | `payments->all()` | `payments.list()` | ⚠️ ancien flux uniquement ([détails](/api-reference/payments/list)) |
| Liens de paiement | `paymentLinks.*` | `paymentLinks->*` | `payment_links.*` | ✅ |
| Webhooks : vérification | `webhooks.constructEvent()` | `webhooks->constructEvent()` | `webhooks.construct_event()` | ✅ |
| Webhooks : test | `webhooks.test()` | `webhooks->test()` | `webhooks.test()` | ✅ |
| Customer Portal | `portal.createSession()` | `portal->createSession()` | `portal.create_session()` | ✅ |
| Plans, abonnements, clients | `plans.*`, `subscriptions.*`, `customers.list()` | idem | idem | ✅ `/v1/billing/*` ([guide](/guides/subscriptions)) |

## Options de paiement communes

| Option | Effet |
|--------|-------|
| `idempotency_key` | Envoyée dans `X-Idempotency-Key` (obligatoire côté API). Les trois SDKs en génèrent une aléatoire si vous ne la fournissez pas ; passez une clé stable liée à votre commande pour que les retries ne créent pas de doublon |
| `hosted_checkout` | `true` par défaut dans les SDKs : `redirect_url` pointe vers le checkout SahelPay |
| `mock` | `metadata.sahelpay_mock = true` : simulateur SahelPay, clé de test uniquement |
| `sandbox` | `metadata.sandbox = true` : sandbox Orange, clé de test uniquement |

## Capabilities

Les helpers `hasCapability()` / `getCapabilities()` / `getMethodsWithCapability()` (JS) et `has_capability()` (Python) sont des tables statiques embarquées dans le SDK. Elles listent encore Wave, Moov, les cartes et des capacités non proposées : **ne vous y fiez pas**. Seul `ORANGE_MONEY` est disponible. Pour la disponibilité réelle, appelez `GET /v1/providers/enabled`.

## Gateway Stream

`GatewayEventSource` / `useGatewayStream()` (JS) et `gateway_stream` (Python) écoutent `/admin/gateways/stream`, un flux réservé à l'administration SahelPay. Ils ne sont pas utilisables avec une clé marchande.
