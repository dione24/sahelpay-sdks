# JavaScript SDK

Le SDK JavaScript officiel pour intégrer SahelPay côté serveur (Node.js, TypeScript).

## Installation

Le paquet `@sahelpay/sdk` n'est pas encore publié sur npm. Installez-le depuis le dépôt :

```bash
git clone https://github.com/dione24/sahelpay-sdks.git
cd sahelpay-sdks/javascript && npm install && npm run build
# puis dans votre projet
npm install /chemin/vers/sahelpay-sdks/javascript
```

Le SDK utilise `fetch` global : Node.js 18 ou plus récent.

## Configuration

```typescript
import SahelPay from '@sahelpay/sdk';

const sahelpay = new SahelPay({
  secretKey: process.env.SAHELPAY_SECRET_KEY!, // sk_test_... ou sk_live_...
  // baseUrl: 'https://api.sahelpay.ml', // défaut, identique en sandbox et en production
});
```

## Créer un paiement

```typescript
const payment = await sahelpay.payments.create({
  amount: 5000,
  currency: 'XOF',
  payment_method: 'ORANGE_MONEY', // seul moyen de paiement
  customer_phone: '+22370123456',
  description: 'Commande #123',
  client_reference: 'order-123',
  return_url: 'https://votre-site.com/checkout/return?order=order-123',
  idempotency_key: 'order-123', // recommandé ; généré automatiquement sinon
});

// Renvoyer l'URL au frontend pour rediriger le client
return { url: payment.redirect_url };
```

- `X-Idempotency-Key` est obligatoire côté API. Fournissez une clé stable (liée à votre commande) pour que les retries ne créent jamais de doublon ; à défaut, le SDK en génère une aléatoire à chaque appel.
- `hosted_checkout` vaut `true` par défaut : `redirect_url` (et `checkout_url`) pointe vers le checkout SahelPay.
- Après un paiement confirmé, le client est renvoyé automatiquement vers `return_url`.
- Partenaires SPAY : passez `items: [{ product_id, quantity }]` (voir [Programme Partenaires SPAY](/guides/partners)).

## Tester sans appel opérateur

L'option `mock` active le simulateur SahelPay : aucun appel opérateur, et le
statut final est piloté par le montant (`4000` réussi, `4001` échoué, `4002` en
attente, `4003` erreur opérateur). À ne pas confondre avec `sandbox`, qui appelle
l'environnement de test de l'opérateur. Les deux sont refusées avec une clé live.

```typescript
const payment = await sahelpay.payments.create({
  amount: 4000,
  payment_method: 'ORANGE_MONEY',
  customer_phone: '+22370123456',
  hosted_checkout: false, // la simulation démarre à l'initiation
  mock: true,
});

const result = await sahelpay.payments.checkStatus(payment.id);
console.log(result.status); // SUCCESS

await sahelpay.webhooks.test(); // envoie webhook.test vers votre endpoint configuré
```

## Vérifier le statut

```typescript
const result = await sahelpay.payments.checkStatus(payment.id);
console.log(result.status); // 'INITIATED' | 'PENDING' | 'SUCCESS' | 'FAILED' | 'EXPIRED'

const byOrder = await sahelpay.payments.search('order-123'); // null si introuvable
```

## Vérifier un webhook

```typescript
export async function POST(request: Request) {
  const rawBody = await request.text();
  const signature = request.headers.get('x-sahelpay-signature');

  if (!signature) {
    return Response.json({ error: 'Invalid signature' }, { status: 401 });
  }

  let event;
  try {
    event = sahelpay.webhooks.constructEvent(
      rawBody,
      signature,
      process.env.SAHELPAY_WEBHOOK_SECRET!
    );
  } catch {
    return Response.json({ error: 'Invalid signature' }, { status: 401 });
  }

  if (event.event === 'payment.success') {
    // Mettre à jour la commande event.data.client_reference
  }

  return Response.json({ received: true });
}
```

## Gestion des erreurs

```typescript
import { SahelPayError } from '@sahelpay/sdk';

try {
  await sahelpay.payments.create({ /* ... */ });
} catch (error) {
  if (error instanceof SahelPayError) {
    console.log(error.code);    // ex. 'IDEMPOTENCY_KEY_REQUIRED'
    console.log(error.message);
  }
}
```

Voir [Codes d'erreur](/resources/error-codes).

## Fonctions à éviter pour l'instant

| Helper | Raison |
|--------|--------|
| `payouts.*`, `refunds.*`, `withdrawals.*` | Hors du périmètre de l'API documentée : ne pas utiliser |
| `hasCapability()` & co. | Table statique non fiable : seul `ORANGE_MONEY` est disponible |
| `GatewayEventSource` / `useGatewayStream()` | Retiré de l'export public (flux admin SahelPay) |
