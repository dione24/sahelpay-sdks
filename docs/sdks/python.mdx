# Python SDK

Le SDK Python officiel pour intégrer SahelPay dans vos applications Python 3.8+, Django ou Flask.

## Installation

Le paquet `sahelpay` n'est pas encore publié sur PyPI. Installez-le depuis le dépôt :

```bash
git clone https://github.com/dione24/sahelpay-sdks.git
cd sahelpay-sdks/python
pip install -e .
```

## Configuration

```python
from sahelpay import Client

sahelpay = Client(secret_key='sk_test_xxx')  # base URL https://api.sahelpay.ml dans tous les cas
```

## Créer un paiement

```python
payment = sahelpay.payments.create(
    amount=5000,
    provider='ORANGE_MONEY',  # seul moyen de paiement
    customer_phone='+22370123456',
    description='Commande #123',
    client_reference='order-123',
    return_url='https://votre-site.com/checkout/return?order=order-123',
    idempotency_key='order-123',  # obligatoire côté API : toujours la fournir
)

redirect(payment.redirect_url)
```

<Warning>
  Sans `idempotency_key`, le SDK génère une clé aléatoire à chaque appel : un retry créerait un second
  paiement. Fournissez une clé stable liée à votre commande. Le SDK n'expose pas encore `items`
  (Partenaires SPAY) : utilisez l'API HTTP pour ces paiements.
</Warning>

`hosted_checkout=True` par défaut : `redirect_url` pointe vers le checkout SahelPay. Après un paiement confirmé, le client est renvoyé automatiquement vers `return_url`.

## Créer un lien de paiement

```python
link = sahelpay.payment_links.create(
    title='Commande #123',
    price=5000,
    redirect_url='https://votre-site.com/merci',
)

redirect(link.url)  # https://pay.sahelpay.ml/<slug>
```

## Vérifier le statut

```python
payment = sahelpay.payments.retrieve(payment.id)   # GET /v1/payments/{id}/status
print(payment.status)  # INITIATED, PENDING, SUCCESS, FAILED, EXPIRED

by_order = sahelpay.payments.search('order-123')   # par client_reference, None si introuvable
```

## Tester sans appel opérateur

L'option `mock` active le simulateur SahelPay (statut piloté par le montant : `4000` réussi, `4001` échoué, `4002` en attente, `4003` erreur opérateur). `sandbox` appelle l'environnement de test d'Orange. Les deux sont refusées avec une clé live.

```python
payment = sahelpay.payments.create(
    amount=4000,
    provider='ORANGE_MONEY',
    customer_phone='+22370123456',
    hosted_checkout=False,  # la simulation démarre à l'initiation
    mock=True,
    idempotency_key='test-4000-1',
)

result = sahelpay.payments.check_status(payment.id)
print(result["status"])  # SUCCESS

sahelpay.webhooks.test()  # envoie webhook.test vers votre endpoint configuré
```

## Vérifier un webhook

```python
# Flask
@app.route('/webhooks/sahelpay', methods=['POST'])
def webhook():
    raw_body = request.get_data(as_text=True)
    signature = request.headers.get('X-SahelPay-Signature', '')

    try:
        event = sahelpay.webhooks.construct_event(
            raw_body,
            signature,
            current_app.config['SAHELPAY_WEBHOOK_SECRET'],
        )
    except Exception:
        return jsonify({'error': 'Invalid signature'}), 401

    if event.event == 'payment.success':
        order_id = event.data.client_reference
        # Mettre à jour la commande

    return jsonify({'received': True})
```

```python
# Django
from django.http import JsonResponse
from django.views.decorators.csrf import csrf_exempt

@csrf_exempt
def webhook(request):
    raw_body = request.body.decode('utf-8')
    signature = request.headers.get('X-SahelPay-Signature', '')

    try:
        event = sahelpay.webhooks.construct_event(
            raw_body, signature, settings.SAHELPAY_WEBHOOK_SECRET,
        )
    except Exception:
        return JsonResponse({'error': 'Invalid signature'}, status=401)

    if event.event == 'payment.success':
        pass  # Mettre à jour la commande

    return JsonResponse({'received': True})
```

<Note>
  `construct_event()` convertit `data` en objet `Payment` uniquement pour les événements `payment.*`.
  Les autres (`invoice.*`, `subscription.*`, `webhook.test`) restent des dictionnaires.
</Note>

## Fonctions à éviter pour l'instant

| Helper | Raison |
|--------|--------|
| `payouts.*`, `refunds.*`, `withdrawals.*` | Hors du périmètre de l'API documentée : ne pas utiliser |
| `has_capability()` & co. | Table statique non fiable : seul Orange Money est disponible |
| `gateway_stream` | Flux réservé à l'administration SahelPay |
