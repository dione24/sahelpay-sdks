# PHP SDK

Le SDK PHP officiel pour intégrer SahelPay dans vos applications PHP 8.1+ et Laravel.

## Installation

Le paquet `sahelpay/sahelpay-php` n'est pas encore publié sur Packagist. Installez-le depuis le dépôt via un *path repository* Composer :

```bash
git clone https://github.com/dione24/sahelpay-sdks.git
```

```json
{
  "repositories": [{ "type": "path", "url": "../sahelpay-sdks/php" }]
}
```

```bash
composer require sahelpay/sahelpay-php:"*"
```

## Configuration

```php
use SahelPay\SahelPay;

$sahelpay = new SahelPay(
    getenv('SAHELPAY_SECRET_KEY'),         // sk_test_... ou sk_live_...
    null,                                   // clé publique (optionnelle)
    ['webhook_secret' => getenv('SAHELPAY_WEBHOOK_SECRET')]
);
```

La base URL est `https://api.sahelpay.ml` en sandbox comme en production ; le mode dépend de la clé.

### Laravel

Le service provider lit `config/sahelpay.php` (`SAHELPAY_SECRET_KEY`, `SAHELPAY_WEBHOOK_SECRET`) et enregistre `SahelPay\SahelPay` en singleton : injectez-le dans vos contrôleurs.

## Créer un paiement

```php
$payment = $sahelpay->payments->initiate([
    'amount' => 5000,
    'provider' => 'ORANGE_MONEY',
    'customer_phone' => '+22370123456',
    'description' => 'Commande #123',
    'client_reference' => 'order-123',
    'return_url' => 'https://votre-site.com/checkout/return?order=order-123',
    'idempotency_key' => 'order-123', // obligatoire côté API : toujours la fournir
]);

header('Location: ' . $payment->redirect_url);
exit;
```

<Note>
  `X-Idempotency-Key` est obligatoire côté API. Sans `idempotency_key`, le SDK génère une clé aléatoire à
  chaque appel : la requête passe, mais un retry créerait un second paiement. Fournissez une clé stable liée à
  votre commande.
</Note>

## Créer un lien de paiement

```php
$link = $sahelpay->paymentLinks->create([
    'name' => 'Commande #123',
    'fixed_amount' => 5000, // prix imposé : le SDK envoie amount_mode FIXED
    'success_redirect_url' => 'https://votre-site.com/merci',
]);

$url = $sahelpay->paymentLinks->getUrl($link->slug); // https://pay.sahelpay.africa/<slug>

$sahelpay->paymentLinks->update($link->id, ['name' => 'Commande #123 (bis)']);
$sahelpay->paymentLinks->delete($link->id); // archivage définitif
```

`title`, `price` (ou `amount`) et `redirect_url` restent acceptés. Sans montant, le lien est à montant libre (`OPEN`).

## Livraisons webhook et paiement sécurisé

```php
$failed = $sahelpay->webhooks->logs(['status' => 'FAILED', 'limit' => 20]);
foreach ($failed->logs as $log) {
    $sahelpay->webhooks->retry($log['id']);
```

## Tester sans appel opérateur

L'option `mock` active le simulateur SahelPay (statut piloté par le montant : `4000` réussi, `4001` échoué, `4002` en attente, `4003` erreur opérateur). `sandbox` appelle l'environnement de test de l'opérateur. Les deux sont refusées avec une clé live.

```php
$payment = $sahelpay->payments->initiate([
    'amount' => 4000,
    'provider' => 'ORANGE_MONEY',
    'customer_phone' => '+22370123456',
    'hosted_checkout' => false,
    'mock' => true,
    'idempotency_key' => 'test-4000-1',
]);

$status = $sahelpay->payments->verify($payment->id);
echo $status->status; // SUCCESS

$sahelpay->webhooks->test(); // envoie webhook.test vers votre endpoint configuré
```

## Vérifier le statut

```php
$payment = $sahelpay->payments->verify('8d6f1c2e-...');   // GET /v1/payments/{id}/status
echo $payment->status; // INITIATED, PENDING, SUCCESS, FAILED, EXPIRED

$byOrder = $sahelpay->payments->search('order-123');      // par client_reference
```

## Vérifier un webhook

`webhooks->constructEvent()` vérifie la signature avec le `webhook_secret` configuré et lève `WebhookSignatureException` si elle est invalide.

```php
use SahelPay\Exceptions\WebhookSignatureException;

$rawBody = file_get_contents('php://input');
$signature = $_SERVER['HTTP_X_SAHELPAY_SIGNATURE'] ?? '';

try {
    $event = $sahelpay->webhooks->constructEvent($rawBody, $signature);
} catch (WebhookSignatureException $e) {
    http_response_code(401);
    exit;
}

if ($event->getType() === 'payment.success') {
    $data = $event->getData(); // client_reference, id, amount...
}

http_response_code(200);
echo json_encode(['received' => true]);
```

### Laravel

```php
public function handle(Request $request, SahelPay $sahelpay)
{
    try {
        $event = $sahelpay->webhooks->constructEvent(
            $request->getContent(),               // corps brut, jamais $request->all()
            $request->header('X-SahelPay-Signature', '')
        );
    } catch (WebhookSignatureException $e) {
        return response()->json(['error' => 'Invalid signature'], 401);
    }

    if ($event->getType() === 'payment.success') {
        // Mettre à jour la commande
    }

    return response()->json(['received' => true]);
}
```

## Fonctions à éviter pour l'instant

| Ressource | Raison |
|-----------|--------|
| `payouts` | Refusé par l'API : les transferts automatiques Orange Money ne sont pas disponibles |
| `refunds` | `POST /v1/refunds` répond `503 REFUNDS_UNAVAILABLE` : contactez SahelPay pour rembourser |
| `withdrawals` | Retraits traités manuellement : demandez-les depuis le dashboard |
| `transactions->get()` | Appelle l'endpoint public de statut ; préférez `payments->verify()` |

Les plans, abonnements et clients passent par `/v1/billing/*`.

## Billing 1.3.0

Clients sans téléphone via `customer_external_ref`/`customer_email`/`customer_id`,
essais (`trial_end`), périodes (`current_period_start/end`), lecture par ID et import.
Les trois SDK exposent aussi les factures et la pagination. ACTIVE ≠ paid : lire la
facture et l'abonnement canoniques avant d'accorder des droits payés.
Voir le [guide Billing français/anglais](/guides/subscriptions) pour les signatures,
les garanties de rejeu et le parcours TEST sans numéro inventé.
